# IOX Stats v0.8.0

Release date: 2026-09-22 - pre-release (`0.x`).

## Highlights

- **The widget comes to the gallery.** `bash scripts/install_widgets.sh` builds the widget signed, installs
  `IOX Stats.app` to `/Applications` and registers it. Then right-click the desktop > **Edit Widgets** >
  **IOX Stats**.
- **First build on real hardware:** the Swift widget compiles on macOS 26.3.2 / Xcode 26.6 / Apple Silicon.
- **Non-commercial community project:** new license (PolyForm Noncommercial 1.0.0), new README, public
  [project status](../PROJECT_STATUS.md).

## Install the widget

```bash
brew install xcodegen
```

```bash
bash scripts/install_widgets.sh
```

No Apple ID in Xcode yet? Xcode > Settings > Accounts > + (a free Apple ID is enough), then run the script again.

## Upgrade notes

- License changed from MIT to PolyForm Noncommercial 1.0.0. Earlier releases stay under the terms they were
  published with.
