# IOX Stats v0.5.0 - "Live"

Release date: 2026-09-20 - pre-release (`0.x`).

## Highlights

- **CPU temperature that works out of the box.** macOS needs no driver: a small helper tool (`macmon` for Apple
  Silicon, `osx-cpu-temp` for Intel) reads the sensors. IOX Stats finds it, or installs it for you through Homebrew
  after asking once - no administrator password.
- **Really live widgets:** the new **Desktop Widget Mode** puts the glass widgets on your desktop, updated every second.
- **The gallery widget now shows the live values of the app**, including the CPU temperature (new value
  *CPU Temperature* in *Edit Widget*).

## What "live" means on macOS

- The IOX Stats window, the menu bar item and Desktop Widget Mode update **every second**.
- A widget in the **macOS widget gallery** is refreshed by macOS, not by the app. The app can only ask for a refresh
  (it does so every 15 seconds while its host app runs), and macOS decides when that really happens. So a gallery
  widget is always a recent snapshot, never a second-by-second readout. This is a limit of macOS, not of IOX Stats.

## Set up the temperature

```bash
python -m iox_stats --install-helpers     # or: menu bar item > Set Up CPU Temperature...
bash scripts/setup_macos.sh               # everything: venv, packages, helper
```

## Update the widget

```bash
cd macos-widgets && xcodegen generate && open IOXStats.xcodeproj
```

Run it once from Xcode again (new files, new entitlement). Open the "IOX Stats" host app: its window shows whether it
receives live data. Keep the IOX Stats Python app running so that the widget gets the values.

## Known limitations

- **Not yet verified on a real Mac**: Swift widget, native menu bar item, Homebrew install flow and desktop window
  behaviour. Send any error message and it will be fixed in a patch release.
- Without the running Python app the gallery widget has no CPU temperature.
- Desktop Widget Mode has no blur-behind.
