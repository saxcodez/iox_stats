# IOX Stats v0.3.0 - "Your Widgets"

Release date: 2026-09-19 - pre-release (`0.x`).

## Highlights

- **Rings, bars or just numbers** - choose the display style for every widget individually.
- **Choose what each widget shows.** Pick from CPU, temperature, memory, swap, disk, ping, download,
  upload, battery and uptime. The number of values is limited by what fits:

  | Style | Small widget | Medium widget |
  |---|---|---|
  | Detailed | 1 | 2 |
  | Rings | 2 | 4 |
  | Bars | 3 | 4 |
  | Numbers only | 3 | 6 |

- **Right-click a widget** to change size, display, values and order, or to add / remove widgets.
  The same options are in the menu bar menu under **Widgets**.
- **Presets**: Detailed, Rings, Bars, Numbers only, Mixed - a good starting point you can fine-tune.

## How to use

1. Right-click a widget (or open the menu bar item > Widgets > the widget).
2. **Display** picks Rings / Bars / Numbers only / Detailed, **Size** picks small or medium.
3. **Values (n of max)** shows which values are on; greyed-out entries would not fit any more - switch one
   off first. A widget always keeps at least one value.

## Install / update

```bash
python -m iox_stats
```

Nothing to reinstall; your settings are kept and gain a `widgets` entry. Resetting to the standard look:
right-click > Reset Layout.

## Known limitations

- The macOS blur-behind, menu bar rendering and login autostart are not yet verified on real Macs.
- Arranging is done via "Move Earlier / Later" - no drag and drop yet.
