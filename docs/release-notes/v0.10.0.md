# IOX Stats v0.10.0

Release date: 2026-09-23 - pre-release (`0.x`).

## Highlights

- **The widget is in the gallery** (since v0.9.1) - confirmed on macOS 26 / Apple Silicon.
- **Looks like Apple's widgets:** iOS Green by default (one green, grey tracks) and a translucent glass
  background. Other palettes and a solid background in *Edit Widget* and in the menu bar app (*Appearance > Colors*).
- **CPU temperature without extra tools on Apple Silicon:** read directly from Apple's sensors, and used
  automatically when `macmon` delivers nothing.
- **The menu bar app is always there:** `bash scripts/start_menubar.sh` starts it now and at every login. It is
  where the menu bar values, 2 / 1 value display and the temperature setup live, and it feeds the widget.
- **Widget app, finished:** Done button, the steps to add the widget, and the status of the menu bar app with a
  copyable start command.

## Update

From the project folder, one line at a time:

```bash
bash scripts/install_widgets.sh
```

```bash
bash scripts/start_menubar.sh
```

No temperature? Run `.venv/bin/python -m iox_stats --diagnose` and send the output.

## Fixed

- Launch at Login did not start the menu bar app from a source install (missing working directory).
- Temperature helper errors were swallowed silently; they are logged now.

## Known limitations

- The IOHID sensor names differ per chip; the CPU value is the mean of the die sensors. Reports from M1-M5 welcome.
