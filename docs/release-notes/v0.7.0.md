# IOX Stats v0.7.0

Release date: 2026-09-22 - pre-release (`0.x`).

## Highlights

- **Menu bar: 2 values or 1 value - your choice.** Menu > *Menu bar values* > **Show 2 values** (default) or
  **Show 1 value**. Select up to 6 values; the ones that do not fit rotate every 4 seconds.
- **macOS community project.** IOX Stats now focuses on macOS only. Owner: saxcodez. Contributions, test reports
  and ideas are welcome - see `CONTRIBUTING.md`.
- **Widget test build:** `bash scripts/build_widgets.sh` compiles the widget gallery widget and writes a log.

## Upgrade notes

- The v0.6.0 option "Rotate through the values" is gone; your selected values stay. The menu bar starts in
  2-value mode.
- The floating "Desktop Widget Mode" is no longer in the menu. The desktop widgets are the macOS widget gallery
  widgets (`macos-widgets/`).

## Known limitations

- The widget gallery widget has not yet been built on a real Mac - `scripts/build_widgets.sh` is the first test.
- No DMG yet; install from source (`bash scripts/setup_macos.sh`).
