# IOX Stats v0.6.0

Release date: 2026-09-22 - pre-release (`0.x`).

## Highlights

- **Menu bar rotation.** Showing several values side by side could crowd out other menu bar icons (e.g. the
  Weather widget). Now IOX Stats shows one value at a time and rotates through your selected values every
  4 seconds - much less horizontal space, and you can select up to 6 values instead of 4. Turn rotation off
  in the menu if you prefer everything shown at once.
- **Log file** for diagnostics, an **About** dialog, and a **Start Hidden** option.

## What changed for you

- Nothing to configure: rotation is on by default. To change it, open the menu bar item's menu and look under
  the values submenu.
- If something misbehaves, choose **Open Log Folder** in the menu (or run `python -m iox_stats --show-log`)
  and send the log file's contents.

## Known limitations

- Not yet verified on a real Mac: rotation, the log file, the About dialog.
- The macOS widget gallery project (`macos-widgets/`) is still unverified on real hardware.
