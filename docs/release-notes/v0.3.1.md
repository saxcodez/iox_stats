# IOX Stats v0.3.1 - macOS menu bar fix

Release date: 2026-09-19 - pre-release (`0.x`).

## What was wrong

On a Mac the menu bar readout was far too small, and with several values the text looked squashed
together. Qt shrinks every menu bar icon into a small square on macOS, so a wide "CPU 12%  T 54°C" picture
cannot work there.

## What changed

- The menu bar now shows **real text** through a native macOS status item: system font at the normal menu
  bar size, correct colours in light and dark menu bars, orange / red for warm / critical values and
  fixed-width digits so the item does not jitter.
- Click the item to open the menu right below it.
- The **Widgets** submenu refreshes reliably after every change.
- Without `pyobjc-framework-Cocoa` a readable square ring icon is used (values in the tooltip).

## Update

```bash
source .venv/bin/activate
pip install -r requirements.txt      # makes sure pyobjc-framework-Cocoa is installed
python -m iox_stats
```

Troubleshooting: `IOX_STATS_NO_NATIVE_STATUSITEM=1 python -m iox_stats` switches back to the old tray icon.

## Good to know

The widgets are shown in the IOX Stats window. They do not appear in the macOS widget gallery
(Notification Center / desktop): only native WidgetKit extensions written in Swift can do that.

## Known limitations

- The native status item has not yet been verified on a real Mac (unit tests use a stand-in).
