# IOX Stats v0.9.0

Release date: 2026-09-23 - pre-release (`0.x`).

## Highlights

- **Widget into the gallery:** `install_widgets.sh` now signs with your Apple ID team (required for macOS to list
  the widget), removes old test builds with the same id and checks the registration.
- **Host app settings page:** Continue button after the guide, then status, refresh interval, Refresh Now,
  start at login and help.
- **`widget_doctor.sh`:** one command that collects everything needed to diagnose a missing widget.

## Install / update the widget

1. Xcode > Settings > Accounts > + > Apple ID (free is fine) - once.
2. From the project folder:

```bash
bash scripts/install_widgets.sh
```

3. Right-click the desktop > Edit Widgets > IOX Stats. Missing? Log out and in, check System Settings >
   Desktop & Dock > Widgets > Show Widgets: On Desktop, then run `bash scripts/widget_doctor.sh`.

## Known limitations

- Widget in the gallery and live values in the widget: still to be confirmed on a real Mac.
- The new host app settings page has been compiled only by CI so far.
