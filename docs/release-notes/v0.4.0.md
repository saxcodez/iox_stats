# IOX Stats v0.4.0 - "Widget Gallery"

Release date: 2026-09-19 - pre-release (`0.x`).

## Highlights

- **IOX Stats in the macOS widget gallery.** A native widget (Swift / WidgetKit) you can put on the desktop or in
  Notification Center, next to Apple's own widgets.
- **Choose it yourself in Edit Widget**: Rings, Bars or Numbers only, and up to six values - CPU, Memory, Swap,
  Disk, Ping, Download, Upload, Battery, Uptime, Thermal State.
- **Same limits as the window**: small = 2 rings / 3 bars / 3 numbers, medium = 4 rings / 4 bars / 6 numbers.
- The **menu bar readout** (v0.3.1) stays as it is - use both.

## Install the widget

The widget lives in the folder `macos-widgets/` and is built with Xcode (free):

```bash
brew install xcodegen
cd macos-widgets
xcodegen generate
open IOXStats.xcodeproj
```

In Xcode choose your **Team** for both targets (*Signing & Capabilities*), press **Run**, then right-click the
desktop > **Edit Widgets** > **IOX Stats**. Details and troubleshooting: `macos-widgets/README.md`.

The Python app is unchanged: `python -m iox_stats`.

## Good to know

- macOS refreshes widgets every few minutes - a widget is a snapshot. The menu bar item is the live readout.
- No CPU temperature in the widget (macOS gives widgets no access); use **Thermal State**. The menu bar app still
  shows the temperature with `macmon` / `osx-cpu-temp`.
- Add the widget several times to show different values.

## Known limitations

- **Not yet run on a real Mac.** The code was written without a Mac; a GitHub Actions job compiles it, but you are
  the first to run it. Send any Xcode error message and it will be fixed in a patch release.
- Requires macOS 14 or newer and Xcode 15 or newer.
