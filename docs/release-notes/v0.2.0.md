# IOX Stats v0.2.0 - "Glass"

Release date: 2026-09-19 - pre-release (`0.x`).

## Highlights

- **Looks like Apple's own widgets.** Glass surface, continuous "squircle" corners, iOS grid sizes,
  system fonts and system colours, SF-Symbols-style icons. Light and dark appearance follow the system.
- **Better displays**: Weather-style temperature gauge, iOS-Storage-style disk widget, battery glyph,
  activity rings, smooth charts with a live end marker, rate/latency numbers with small units.
- **Launch at Login** - your choice: one question on first launch (default No) and a checkbox in the
  menu bar menu you can switch off at any time. Autostart opens quietly in the menu bar.

## Install / update

```bash
pip install -r requirements.txt        # now also installs pyobjc-framework-Cocoa on macOS (glass blur)
python -m iox_stats
```

Nothing else to do; settings are kept. CPU temperature on macOS still needs `brew install macmon`
(Apple Silicon) or `brew install osx-cpu-temp` (Intel).

## Good to know

- Autostart uses a per-user LaunchAgent (macOS), the per-user `Run` registry key (Windows) or an
  autostart entry (Linux). Switching it off removes exactly that entry.
- If the blur behind the window looks wrong on your Mac, set `"glass": false` in `settings.json`
  (macOS: `~/Library/Application Support/IOXStats/settings.json`) or start with `IOX_STATS_NO_NATIVE_BLUR=1`.

## Known limitations

- The macOS blur-behind and menu bar rendering are not yet verified on real hardware.
- Windows shows a simulated glass backdrop (no acrylic/Mica yet).
- macOS still shows a Dock icon while running (menu-bar-only mode is planned).

## Upgrade notes

- Minimum PySide6 is now 6.7. Re-run `pip install -r requirements.txt`.
- The dashboard has no in-window header any more; the version is shown in the window title and the menu.
