# IOX Stats 1.0.0

Release date: 2026-09-23 - **first public release**.

Your Mac's vital signs, dressed like iOS widgets: CPU, memory, disk, network, ping and the CPU temperature -
live in the menu bar, as glass widgets and in the macOS widget gallery. A non-commercial community project by
saxcodez.

## What you get

- **Menu bar readout**, live every second: 2 values or 1 value, up to 6 selected - the rest rotate.
- **Glass widget window**: rings, bars, numbers or detailed; you choose size and values per widget.
- **macOS widget gallery widget** (WidgetKit): right-click the desktop > Edit Widgets > IOX Stats. Rings, bars or
  numbers, up to 6 values, fed with the app's live data.
- **CPU temperature** on Apple Silicon straight from the SoC sensors (no tool, no driver, no sudo); macmon /
  osx-cpu-temp are supported too.
- **iOS Green** colours and a glass background like Apple's own widgets - or Colorful / an accent of your choice.
- Launch at Login, Start Hidden, log file, `--diagnose`, About. No data collection.

## Install

Requirements: macOS 14+, Python 3.9+ (`brew install python`). For the widget: Xcode (free) with your Apple ID
under Xcode > Settings > Accounts, and `brew install xcodegen`.

Download `IOX_Stats_v1.0.0.zip` below, unzip it, open Terminal in the folder and run one line at a time:

```bash
bash scripts/setup_macos.sh
```

```bash
bash scripts/start_menubar.sh
```

```bash
bash scripts/install_widgets.sh
```

Then click the IOX Stats item in the menu bar, and add the widget: right-click the desktop > Edit Widgets >
IOX Stats.

## Good to know

- Gallery widgets refresh when macOS allows it, never every second - the menu bar item is the live readout.
- Something missing? `python -m iox_stats --diagnose` and the log (menu > Open Log Folder) - attach both to an
  [issue](https://github.com/saxcodez/iox_stats/issues/new/choose).
- Tested on macOS 26 / Apple Silicon. Reports from Intel Macs and other chips are very welcome - see
  [docs/PROJECT_STATUS.md](../PROJECT_STATUS.md).
