# IOX Stats v0.1.0 - "First Light"

Release date: 2026-09-18 - first tagged release (pre-release, `0.x`).

## Highlights

- **iOS-style widget dashboard**: CPU and memory rings, temperature gauge, disk bar, network and ping
  sparklines, per-core CPU bars, uptime and battery - in light and dark mode.
- **Live menu bar / tray readout**: pick up to four values (e.g. CPU temperature, ping, CPU load) and
  see them at a glance, colour-coded when they get warm or slow.
- **Cross-platform**: macOS, Windows, Linux (Python + Qt / PySide6).

## Install / run

```bash
python3 -m venv .venv && source .venv/bin/activate      # Windows: .venv\Scripts\activate
pip install -r requirements.txt
python -m iox_stats
```

On macOS, for CPU temperature install one helper (no sudo needed):

```bash
brew install macmon          # Apple Silicon (M1-M5)
brew install osx-cpu-temp    # Intel Macs
```

Pre-built app bundles are attached to the GitHub Release when it is created by the release workflow.

## Known limitations

- The macOS menu bar and Windows tray icons have not yet been verified on real machines
  (rendering is tested headlessly).
- macOS still shows a Dock icon while running; no autostart yet.
- CPU temperature is "n/a" on systems without a readable sensor.
