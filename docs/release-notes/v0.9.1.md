# IOX Stats v0.9.1

Release date: 2026-09-23 - patch release (pre-release `0.x`).

## Fix

The widget did not appear in *Edit Widgets*. The system log said why: `plug-ins must be sandboxed`.
XcodeGen regenerates the `.entitlements` files from `macos-widgets/project.yml` on every build, and they came out
empty - so the widget lost its App Sandbox. The entitlements now live in `project.yml`, the install script refuses
to install a widget without sandbox, and a test guards against it coming back.

## Update

From the project folder:

```bash
bash scripts/install_widgets.sh
```

It should end with `RESULT: WIDGET REGISTERED`. Then right-click the desktop > Edit Widgets > IOX Stats.
